# Beecrowd 1035 - Teste de Seleção 1



## Descrição



Este programa resolve o problema 1035 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém quatro valores inteiros A, B, C e D.



## Saída



O programa apresenta "Valores aceitos" caso todas as condições sejam atendidas, ou "Valores nao aceitos" caso contrário.
